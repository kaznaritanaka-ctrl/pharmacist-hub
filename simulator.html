資産寿命シミュレータ

「NISA貧乏か老後貧乏か」を感覚で悩む前に、一度計算してみるための道具です。資産形成の途中（形成期）と、FIRE後の取り崩し（取り崩し期）で資産配分を変えながら、資産が何歳まで持つかを年次モンテカルロ計算で確認できます。

できること

  • 形成期・取り崩し期ごとに、資産配分とプリセットを設定できます。
  • 積立、支出、年金、売却時の実効税率、名目／実質リターンを条件として入れられます。
  • 結果は資産枯渇の有無だけでなく、ご自身が指定した条件への抵触も「計画未達」として判定します。
  • シミュレーションの95%推定区間や、年齢別の未達経路、代表シナリオを確認できます。
  • 条件は URL フラグメントで共有できます（共有先で保存済みの設定を自動で上書きしません）。

入手先と紹介記事

シミュレータは無料で公開しています。ソースコードは GitHub で公開しており、計算モデルの前提もリポジトリ内の README に記載しています。

  • ソースコード（GitHub）：kaznaritanaka-ctrl/asset-longevity-simulator-v1
  • 紹介記事（note）：「NISA貧乏か老後貧乏か、の前に一度計算すればいい（シミュレータあり）」 — 5,000万円FIREの条件を実際に入れ替えて検討した記録です。

シミュレータ本体は、次のリンクから開けます：資産寿命シミュレータ（公開中の本体）

計算モデルの前提（要点）

  • 資産クラスごとの算術平均リターンと年率ボラティリティ、相関行列から、相関付き正規乱数で年次リターンを生成します。
  • 年1回リバランスし、FIRE年齢の前後で配分を切り替えます。
  • 税率は、収益の厳密な課税所得計算ではなく、売却額に対する実効税負担率として扱います。
  • 本ツールは将来の成果を保証するものではなく、投資・税務・法務上の助言ではありません。

データ出典と帰属表示

計算の参照データには、株式・国債・手形、CPI、対ドル為替について Jordà–Schularick–Taylor Macrohistory Database（macrohistory.net）を使用しています。同データベースは CC BY-NC-SA 4.0 の条件で提供されており、帰属表示・非営利利用・同一条件での共有が求められます。リターン系列の出典論文は Òscar Jordà, Katharina Knoll, Dmitry Kuvshinov, Moritz Schularick, Alan M. Taylor, “The Rate of Return on Everything, 1870–2015,” Quarterly Journal of Economics 134(3), 2019 です。金価格の長期系列には World Bank Commodity Price Data（The Pink Sheet）を参照しています。
