# pharmacist-hub

薬剤師の資産形成・起業・FIREを目指すための総合支援サイト（pharma.ai-investment-research.net）のソースです。

## 5つのコンテンツ

- 資産寿命シミュレータ（案内ページ: simulator.html）— このサイトの指針となるコンテンツ
- 戦略記事（strategy.html）— 要約版を掲載し、全文は note で公開
- 転職情報（strategy.html 内「1. 薬剤師としての労働力を生かす」）
- 投資コンテンツ（note への導線）
- 土地の未来図（land.html、不動産投資の入口）

## 戦略上の4つの部品

「部品」という言葉は、戦略上の武器である4要素（仕事選び・自分の事業・不動産投資・株式投資）だけを指して使います（トップページの「組み立ての地図」参照）。シミュレータはコンテンツであり指針ですが、部品とは呼びません。

素の HTML+CSS の静的サイトです。デプロイは Cloudflare を想定しています。
